# CV — COMPLETAR

Pega aquí tu CV completo en texto (experiencia, logros con números, educación,
herramientas, idiomas, certificaciones). Claude lo lee entero para puntuar cada
oferta y para redactar las cartas, así que mientras más concreto, mejores
resultados.

Para postular por email, pon también tu CV en PDF en `config/cv.pdf`
(no se sube al repo si no quieres: puedes cargarlo como secreto, ver README).
